# Review queue UI fixes — September 14, 2026

Deployed to the active anomaly-review dashboard at http://142.104.222.2:18053/ on oncvm-daq, located through the Codex task **Restore hydrophone prediction** in selfsupervision_anomalies.

## Changes

- Card and spectrogram-dialog buttons say **Edit labels** in Verify and Label modes.
- The live command bar explicitly displays **Page N of M**, including **Page 0 of 0** for an empty result set.
- The summary displays **N clips left to verify**, counted across all pages under the current class, confidence, and status filters. Matching clip count and dataset totals remain separately visible.
- Accepted/rejected drafts remain in **Unverified only** until saved. Saving from a card, spectrogram dialog, label editor, or save-on-close prompt immediately refreshes the filtered grid and counts. The open spectrogram dialog can still display the just-saved item until closed; it no longer appears in the filtered grid.
- Page state clamps when filtering or saving removes the last page.
- Review updates preserve the full server cache identity. Compact All Dates previews are not patched using indices from the full dataset.

## Reproduced bug

On the live dashboard, accepting one label under All Dates reduced **8,579 matching clips to 50**, and pagination fell from **537 to 4 pages**. The badge callback replaced the browser summary with a cached summary that omitted `verify_modal_cache_key`. The next cache synchronization consequently registered the 50-item browser preview as the entire dataset. Saving inside the spectrogram dialog also returned no grid update.

The fix preserves the full cache key in summaries and uses a shared review-store patch helper. Compact previews retain their bounded size; filtering and item lookup use the full server cache. All save paths notify the grid after updating the cache.
